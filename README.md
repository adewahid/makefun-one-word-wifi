## The word

**grumpy**

Home Wi-Fi, personified: it works in the morning, refuses in the evening,
and nobody can explain why. Funny at once, true at once — and short enough
to be a network name.

## How it works

`main.ts` writes the single word `grumpy` to `/output/entry.txt` (UTF-8,
6 characters, within the 1–20 character gate).

```sh
node main.ts
cat /output/entry.txt  # grumpy
```
